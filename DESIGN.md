# Approved terminal design

Use the owner's approved Network Configuration Backup terminal concepts as visual authority. Preserve charcoal backgrounds (#1c2126), warm light text (#edf2f6), fuchsia identity (#ff4c8b), cyan actions/focus (#65cfda), and amber warnings (#ffce75). Standard terminal monospace, native Textual controls and square borders translate the raster concept into terminal cells; fonts are supplied by the user's terminal.

A fixed five-step left rail, task heading, scrollable working panel, persistent operation status and footer keyboard hints provide the structure. Wide terminals show credential forms and command selection in two columns. Below 105 columns, stack columns and actions; retain vertical scrolling and complete labels. Minimum tested size is 80×30.

Use real DataTables for inventory, plans and results, masked Inputs for secrets, Select for assignment scopes, Checkbox for profile selection and explicit export/discard acknowledgments. Read failure reasons as text, not color alone. Keep disabled/loading states during workers and cooperative cancellation. Evidence screenshots must come from actual application widgets using the visibly labeled offline adapter.
